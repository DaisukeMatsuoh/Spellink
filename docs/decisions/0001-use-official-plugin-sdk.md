# 0001. 拡張方式に公式プラグイン SDK を採用する

- 状態: Accepted
- 日付: 2026-10-30

## 背景
「ラッソで囲んだ手書き → Claude → 回答を筆跡で書き戻す」を、軽く・速く・省電力に実現したい。
候補は 公式プラグイン（sn-plugin-lib, React Native 0.79.2）/ サイドロード APK / .note ファイル同期解析 / root 化。
詳細: `docs/notes/research/2026-10-30-supernote-platform-survey.md`

## 決定
公式プラグイン SDK（`sn-plugin-lib`）で実装する。ラッソツールバーボタンを `showType: 0`（UI 無し）で登録し、
ボタン押下時だけ処理を走らせる。重い処理が必要になったら同梱の Java/Kotlin TurboModule に移す。

## 理由
- 必要な機能（ラッソ取得・端末内手書き認識・ストローク挿入）がすべて公式 API にある。
- サイドロード APK は NOTE 内部に触れず、純正の低遅延ペン描画を捨てることになる。スイッチ自体も過去に一度削除されている。
- root 化は保証・アップデート耐性・文鎮化リスクの面で割に合わない。
- PluginHost は常駐しているので、イベント駆動にすれば待機コストはほぼゼロ。

## 結果
- RN 0.79.2 固定。JS のみならこの ARM64 Linux 機で Node だけでビルドできる。ネイティブモジュールを足す場合は x86_64 機か CI が必要。
- 公式 API の範囲外（例: 純正ラッソの挙動自体の変更）はできない。
