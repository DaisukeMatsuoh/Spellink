# 0002. 手書きのテキスト化は端末内認識を第一にする

- 状態: Proposed（日本語の認識精度と所要時間を実機で確認後に Accepted へ）
- 日付: 2026-10-30

## 背景
選択肢は ①`PluginCommAPI.recognizeElements`（ファーム内蔵認識）②`generateLassoPreview` の PNG を Claude Vision に送る
③`Stroke.recognPoints`（時系列点列）を外部のベクタ手書き認識サービスに送る。

## 決定（案）
①の認識テキストを送るのを基本とし、②の PNG を併送するかは計測して決める。③は SaaS 化の候補として保留。

## 理由
- ①はオフライン・無料・速い。送るのはテキストなので通信量が最小。
- 認識誤りは Claude 側で文脈補正できる見込み。図や数式は②で補う。

## 検証項目
- 日本語・英語混在メモでの認識精度、所要時間。
- `size` 引数にはページ全体サイズ（`getPageSize`）を渡す（ラッソ矩形だと失敗するとの報告あり）。
