# 0004. MVP は端末から Claude API を直接呼ぶ（BYOK）

- 状態: Superseded by 0005（2026-10-30）
- 日付: 2026-10-30

## 背景
端末→Claude の経路は ①端末から Anthropic API を直接（ユーザー自身の API キー）②自前の中継サーバ経由。

## 決定（案）
MVP は①。キーは `MyStyle/` 配下の設定ファイル（または初回入力してプラグイン専用ディレクトリに保存）。
`plugin.permission.INTERNET` を宣言し、起動ごとに check→request する。

## 理由
- サーバ不要で最短で動く。レイテンシも最小。
- SaaS 化（キー秘匿、ベクタ OCR、筆跡スタイル学習、課金）が具体化した段階で②に移行する。そのときに本 ADR を Superseded にする。

## 注意
- 使用モデル ID は実装時に最新を確認する（応答速度重視なら小型モデル、質重視なら上位モデル）。
