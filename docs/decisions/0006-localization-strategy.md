# 0006. UI と筆跡出力のローカライズ方針

- 状態: Accepted（日本語・英語の範囲。中国語・スペイン語・韓国語は未着手）
- 日付: 2026-10-30

## 背景
メインは日本語、英語も同等に扱いたい。将来は中国語・スペイン語・韓国語なども。
ローカライズは2層ある: (1) ボタン名・メッセージなどの UI 文字列、(2) **回答を筆跡にするための単線グリフデータ**（文字体系ごとに別データが要る）。
(1) は SDK に言語変更リスナー（`registerLangListener`）があり、ボタン名もローカライズ可能なので安い。(2) が本当のコスト。

## 決定（案）
- UI 文字列は最初から ja / en のメッセージカタログで持つ（ハードコード禁止）。
- 筆跡データは文字体系単位で追加する:
  | 言語 | 候補データ | ライセンス |
  |---|---|---|
  | 日本語（かな・漢字） | KanjiVG | CC BY-SA 3.0 |
  | 英語・ラテン文字 | Hershey 系単線フォント（アクセント記号付きが必要なら OFL の単線フォントを検討） | ほぼ自由 / OFL |
  | 中国語（簡体・繁体） | Make Me a Hanzi（筆順の中心線データ） | Arphic Public License 等（要確認） |
  | 韓国語 | 字母（ジャモ）の単線データから合成 | 要調査 |
- グリフが無い文字はテキストボックスに切り替える（文字単位ではなく回答単位で切り替え、見た目の混在を避ける）。
- 手書き認識の言語は端末の認識言語設定に従う（プラグイン側では選べない想定。要確認）。

## 次の言語の優先度
Supernote の国別販売データは公開情報で見つからなかった。開発元 Ratta が中国企業で、公式開発者ドキュメントが英語と中国語で出ていることから、
**中国語（簡体/繁体）を次点** とし、スペイン語・ドイツ語・韓国語はユーザーの要望を見て決める。

## 追記（2026-11-07）: 実装の範囲
- プラグインの UI 文字列は、日本語・英語を実装済み（`plugin/src/i18n.ts`。端末の言語に追従）。回答の筆跡は、漢字・かな・英数字のグリフに対応済み。
- 中国語・スペイン語・韓国語は、文字データと UI 文字列の追加が要る。着手するときに、この ADR を更新する。
- 利用者向けの呼称は、ADR 0015 で「AIに聞く」/ "Ask AI" に中立化する予定（文言の変更を伴う）。

## 追記（2026-11-20）: Supernote が提供する言語（調べた結果）
- **手書き認識の言語**（Supernote の公式ページ「Handwriting Recognition」）: 約 65 言語。英語（米・英・加・比・南ア）、中国語（簡体・繁体〔台湾・香港〕）、日本語、韓国語、フランス語（仏・加）、ドイツ語（独・墺）、スペイン語（西・墨・コロンビア）、イタリア語、ポルトガル語（伯・葡）、ロシア語、ウクライナ語、トルコ語、ギリシャ語、ベトナム語、インドネシア語、ポーランド語、チェコ語ほか。アラビア語・ヘブライ語・タイ語・ヒンディー語は**ない**。一覧: https://support.supernote.com/handwriting-recognition
- **本体の表示言語**（Supernote Manta の製品ページの仕様）: 英語・日本語・簡体字中国語・繁体字中国語（`en`・`ja`・`zh_CN`・`zh_TW`）。製品ページの記載で、設定画面の一覧ではない。**実機の設定で確認する**。Nomad の個別の記載は見つからなかった（同じファームウェアの系列）。
- 意味: 質問（手書き）は約 65 言語で来うる。**回答を筆跡にするには、文字体系ごとの単線グリフが要る**。
  | 文字体系 | 言語の例 | グリフの候補 | 状況 |
  |---|---|---|---|
  | 漢字・かな | 日本語 | KanjiVG（CC BY-SA 3.0） | 済み |
  | ラテン（ASCII） | 英語 | Hershey | 済み |
  | ラテン（アクセント付き） | 仏・独・西・伊・葡・ポーランド・チェコ・トルコ・ベトナム ほか | 基本字形＋アクセントの合成 | **未着手**（要設計） |
  | キリル | ロシア・ウクライナ・ブルガリア ほか | Hershey にキリル文字の集合がある | **未着手**（要確認） |
  | ギリシャ | ギリシャ語 | Hershey にギリシャ文字の集合がある | **未着手**（要確認） |
  | ハングル | 韓国語 | 字母（ジャモ）の単線から合成 | **未着手**（データの出どころを要調査） |
  | 中国語の漢字 | 簡体・繁体 | Make Me a Hanzi（Arphic Public License 等） | **未着手**（ライセンス要確認） |
  | アルメニア・ジョージア | — | 出どころ未確認 | 当面は対象外 |
  グリフがない文字を含む回答は、回答単位でテキストボックスに切り替える（上の決定どおり）。**ペアリングの手書きの文言も同じ**: 字がなければ普通の文字で出る。
- UI の文言: 本体の 4 言語（en・ja・zh_CN・zh_TW）を、TSV の列として足す。手書き認識の 65 言語それぞれの UI の翻訳までは、本体の言語に無いので、当面は不要（認識された言語に関わらず、UI は本体の言語で出る）。
- 質問の言語に合わせて AI に答えさせる（`lang` は今 `ja`・`en` だけ）ことも、同じ表に乗る。
