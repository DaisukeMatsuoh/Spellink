# 0015. 問い合わせ先の AI を差し替え可能な「プロバイダ」にし、利用者向けの呼称を中立にする

- 状態: Proposed（ユーザー要望 2026-11-07。実装はユーザーによる状態遷移表の確認後）
- 日付: 2026-11-07

## 背景
現状は、ブリッジが公式の Claude Code CLI を呼ぶ（ADR 0005）。ボタン名や文言も「Claude に聞く」になっている。
将来は、ChatGPT などを使う人にも届けたい。AI が変わっても動き、認証と問い合わせ先を、モジュールとして差し替えられるようにしたい（ユーザー要望）。

## 決定
1. **利用者向けの呼称は中立にする。** ボタン・進捗・設定・エラーの文言は「AIに聞く」/ "Ask AI"。特定の AI の名前は、**設定画面の「接続先」の表示**と、診断にだけ出す。
2. **ブリッジに「プロバイダ」の境界を置く。** ブリッジの他の部分（run、ページ配置、履歴、再接続）は、プロバイダの中身を知らない。
   ```go
   // internal/provider
   type Request struct {
       System   string         // 回答の書式・長さの指示（プロバイダに依存しない文面）
       Earlier  []history.Turn // 同じノートの、これまでの質問と回答
       Question string
       Lang     string
   }
   type Provider interface {
       Name() string                                                    // 設定画面に出す名前
       Ask(ctx context.Context, r Request, onText func(string)) (string, error)
   }
   ```
   Request をどう相手に渡すかはプロバイダの責務（CLI なら 1 本のテキストに組み立てる。API ならメッセージの配列にする）。
3. **認証はプロバイダの責務で、端末（プラグイン）には一切渡さない。**
   - CLI 型（Claude Code、Codex CLI など）: 各 CLI のログイン状態をそのまま使う。ブリッジは資格情報に触れない。
   - API 型: 鍵は、ブリッジの `config.json`（0600）または環境変数に置く。ブリッジ以外へは出さない。
   - 端末とブリッジの間の認証（トークン + Noise、ADR 0007）とは別のもの。
4. **設定**: `config.json` の `provider` に種類と設定を書く。例: `{"kind": "claude-code", "model": "haiku"}`。未知の `kind` は、ファイル名つきのエラーで起動を止める。複数を登録し、既定を選べる形に拡張できるようにしておく。
5. **最初のプロバイダは `claude-code`（現行）。** 候補: `codex-cli`（ChatGPT の契約で公式 CLI を使う。ADR 0005 と同じく、**追加の前に、規約を確認する**）、`openai-compatible`（API。BYOK やローカルのモデル）。
6. **失敗の種類をプロバイダ共通にする。** 起動できない、未ログイン、利用上限、無応答、その他。端末の文言はこの種類から作り、特定の AI の名前を出さない。
7. **時間切れは run が持つ**（プロバイダに依存しない）。状態遷移表 `bridge-run.md` の B10 は PROVIDER-FAIL、B16 は PROVIDER-HANG に読み替える。
8. 回答の書式の指示（`SystemPrompt`）は、すでに特定の AI に依存しない文面なので、プロバイダの外（共通）へ移す。

## 理由
- 「問い合わせ先」と「回答を手書きにする部分」を分けるのが、このプロダクトの価値の中心。AI が変わっても、後者は変わらない。
- 認証をプロバイダに閉じることで、サブスクリプション（CLI）と API 課金のどちらの利用者も受け入れられる。
- 中立な呼称は、特定企業の商標・ガイドラインに依存しない（`docs/notes/research/2026-10-31-naming.md` の注意）。

## 結果・注意
- コードの変更範囲: `internal/claude` → `internal/provider/claudecode`、共通部分（`SystemPrompt`、`Request`）の切り出し、`Deps.Ask` を `Provider` に、`config.Config` に `Provider`、i18n と README の文言。プラグインとブリッジの通信（プロトコル）は変えない。
- 履歴（ADR 0012）は、すでにプロバイダ非依存の形（質問と回答の組）で保存している。プロバイダを替えても、会話は続く。
- AI ごとに、回答の長さの指示への従い方や、「考えている時間」が違う。時間切れの値は設定で変えられるようにする（`bridge-run.md` の R13）。
- 他社の AI の規約・料金・認証方式は、追加するときに調べる。このファイルでは決めない。
