# 0020. 運営の形: 中継は運営する・寄付で始める・ペアリングは QR と 8 桁・対応 OS

- 状態: Accepted（ユーザーが決定。2026-11-22）
- 関連: ADR 0010（中継）、0016（ペアリング）、0017・0019（名前サービスと運営の入口）

## 決定
1. **中継（リレー）は、Spellink が運営する。** 利用者に Cloudflare のトンネルやドメインを求めない。トンネルは、上級者が自分でやる道として残す（`docs/guides/cloudflare-tunnel-setup.md`）。
2. **サーバー代は、最初は寄付でまかなう。** 機能を寄付の有無で制限しない。寄付の入口（Buy Me a Coffee、暗号通貨の送金先）は、GitHub の README・`.github/FUNDING.yml`・ブリッジのアプリ（できたら）に置く。
3. **ペアリングは、端末に出る QR と 8 桁のコードを基本とする**（ADR 0016 のとおり。8 桁の入力が主、QR は近道）。
4. **対応 OS は、ブリッジが Windows・macOS・Linux。** 端末は Supernote（Nomad・Manta）。

## 結果・残る作業
- 運営の費用は小さい（VPS 1 台、定額）が、止まったときの責任がある。利用規約・プライバシーの文書が要る（名前サービスが見るのは ID と家の IP、証明書は公開の記録に載る）。
- 寄付の入口は、アカウントの作成と送金先の用意（利用者本人）が先。コードやページ側は、その値を入れるだけにしておく。
- Windows と macOS は、実機で未確認。macOS の公証、Windows の自動起動は未。
