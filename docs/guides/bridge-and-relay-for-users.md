# ブリッジとリレーを使う人が知っておくこと・やること（整理用）

利用者向けの説明（README・セットアップ手順）と、運営側の作業の洗い出し。**決まっていないことは「未決」と書いてある。** 整理しながら更新する（日付つきで追記）。

最終更新: 2026-11-07

## 1. 全体像（利用者に最初に伝えること）
- Supernote のプラグインは、手書きを端末内で文字にして、**あなたのパソコン（ブリッジ）**に送る。ブリッジが AI に聞き、答えを手書きの筆跡にして返す。
- **ブリッジは、利用者ごとに自分のパソコンで動かす。** 一つのブリッジを複数人で使う作りではない（トークン 1 つが、そのブリッジの全部の権限）。
- AI の認証（ログイン）は、**ブリッジのパソコンにある公式の AI ツール**が持つ。プラグイン（端末）にも、Spellink の運営にも、渡らない。
- 端末とブリッジの間は、端末とブリッジだけが持つ鍵で暗号化する（Noise）。通り道（トンネル、中継）に中身は見えない。

## 2. 利用者が用意するもの
| 必要なもの | 内容 | 補足 |
|---|---|---|
| Supernote | Nomad または Manta（確認済みは Nomad、Chauvet 3.31.45） | プラグインの導入は `.snplg` を端末に入れる。**OS 更新前に作ったノートではボタンが出ない。新しいノートで試す** |
| 常時つながるパソコン | Mac / Linux / Windows（Windows は未確認） | **スリープすると動かない。** 家の中に置いておく |
| AI の契約 | 現状は Claude の契約（Pro / Max など）。公式の Claude Code をそのパソコンで使えるように、ログイン済みにする | API キーは使わない。**契約は本人のもの。複数人で 1 契約を共有しない**（規約上） |
| ブリッジ（`spellink-bridge`） | 単一の実行ファイル。`serve` で起動。**`spellink-bridge service install` で、パソコンの起動と一緒に自動で起動する**（Linux は systemd のユーザーサービス、Mac は launchd、Windows はタスク スケジューラ。管理者権限は要らない。`--dry-run` で、先に何をするか見られる） | 初回起動で、文字データ（KanjiVG などから生成）をダウンロードして作る。インターネットが要る |
| 端末からブリッジへの道 | 次の §3 から 1 つ選ぶ | 端末は **公的な認証局の証明書つきの `wss://` しか使えない**（平文の `ws://`、`.local` は不可） |

## 3. 端末からブリッジへの道（選ぶ）
| 方法 | 利用者がやること | 利点 | 欠点 | 状況 |
|---|---|---|---|---|
| A. 自分で Cloudflare のトンネル | ドメインを取る（年 1,500 円前後）、Cloudflare に追加、トンネルを作る、ホスト名を `localhost:8765`（**HTTP**）に割り当てる。手順書: `docs/guides/cloudflare-tunnel-setup.md` | 運営に頼らない。固定の URL。無料プランで足りる | 手間が大きく、一般の利用者には難しい | 開発者本人が使用中 |
| B. Spellink の中継（リレー） | 中継の URL とペアリング情報を設定するだけ | **利用者の設定が最小。ドメインもトンネルも要らない** | 運営が要る（§5）。中継は、暗号化された通信と、どのブリッジの部屋かだけを知る | 実装済み。運営は**未決** |
| C. 家の中の直結 | ドメイン、Cloudflare の API トークン（DNS の編集のみ、そのドメインだけ）を設定 | 家の中は速い | 外では使えない。設定が難しい | 実装済み、実証明書での確認は**未** |

複数同時に設定でき、端末は同時に試して、つながったものを使う。

## 4. 利用者の日常と注意
- **ペアリング情報（トークン）は人に見せない。** 漏れたら、`config.json` の `token` を消してブリッジを再起動し、ペアリングをやり直す。
- **ペアリング情報を端末に入れる方法は未決**（現状は、開発者がビルドに埋め込んでいる。公開版では使えない）。
- 端末の権限（ファイル読み書き・インターネット）の許可が要る。「今回だけ許可」は、プラグインを閉じると切れる。
- 設定（字間・傾き・通知）と、会話の記憶は、**ブリッジのパソコンに保存**される。会話の履歴は暗号化していない（そのパソコンのホームの下、本人だけが読める権限）。「会話を忘れさせる」で消せる。
- 質問には、AI の利用上限（契約のプランの枠）が使われる。
- ブリッジのパソコンが止まっている、スリープしている、ネットが切れているときは、答えが返らない（エラーが出る）。
- 回答の途中で通信が切れても、続きを受け取れる（再接続を最大 3 回試す）。
- 一度に 1 つの質問。回答中にもう一度押すと、短い通知が出る（設定でオフにできる）。
- 回答の最中に**別のノートを開く**と、書くのを止める（別のノートには書かない）。
- 文字として読めないもの（楽譜・絵）を囲むと、「読み取れない」と出る。
- ブリッジは、AI のツールを無効にし、空のフォルダで動かす。利用者のファイルは AI から見えない。

## 6. よくある失敗（セットアップの手順書に入れる）
- **まず `spellink-bridge check`**: 端末と同じ道で、暗号化の握手まで確かめる。OK なら、道は通っている。NG の理由（接続できない／握手できない＝トークン違い）が出る。
- 502: トンネルの Service が `HTTPS` になっている → `HTTP` にする。
- 端末にボタンが出ない: OS 更新前に作ったノート → 新しいノートで試す。
- `closed (1006)`: 通信が切れた → 再接続で続く。頻発なら、トンネルのログを見る。
- 「ブリッジに接続できません」: ブリッジが動いていない、またはパソコンがスリープ。
- 認識が空: 文字でないものを囲んだ。
