# 1. はじめに

## できること
1. ノートに質問を手書きする。
2. ラッソで囲み、プラグインのボタン(**AI に聞く**)を押す。
3. 数秒〜数十秒で、答えが質問の下に、筆跡で書かれる。続きを書くと、会話が続く。

## 用意するもの
| もの | 内容 |
|---|---|
| Supernote | Nomad(確認済み)または Manta。プラグインを入れるための、USB ケーブルか、端末にファイルを送る方法 |
| パソコン | Windows / macOS / Linux。**つけたままにします**(スリープすると答えが返りません)。インターネットにつながっていること。確認済みは Linux だけです |
| Claude の契約 | Pro / Max など、**本人の契約**。複数人で共有しません。API キーは要りません |
| Claude Code | 公式のもの。パソコンに入れ、`claude` と打って**ログインを済ませておく**。Spellink は、そのログインをそのまま使います |

## 費用
- Spellink 自体は無料です(Apache-2.0)。
- 質問のたびに、**あなたの Claude 契約の利用枠**が使われます。
- 端末が外出先から使うための**中継**は、運営の寄付で賄います。使うかどうかは任意で、機能は寄付の有無で変わりません。
- 自分のドメインとトンネルを使う道は、上級者向けで、費用がかかることがあります。**使わなくて構いません。**

## 最短の手順
1. [ブリッジを入れる](02-bridge.md): ダウンロード → `spellink-bridge serve` → `spellink-bridge service install`
2. [端末を登録する](03-device.md#登録): `spellink-bridge device add my-nomad`(設置ファイルができる)
3. [端末に入れる](03-device.md#端末に入れる): 設置ファイルを `MyStyle` に入れ、端末からインストール
4. [ペアリングする](03-device.md#ペアリング): 端末の 8 桁を、パソコンで `spellink-bridge device pair` に入れる
5. 新しいノートで、手書き → 囲む → **AI に聞く**
