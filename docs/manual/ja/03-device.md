# 3. 端末をつなぐ

端末は、**公的な証明書つきの `wss://`** にしかつながれません。そのため、ブリッジまでの道を 1 つ選びます。

## つなぐ道を選ぶ
| 道 | 向く人 | やること |
|---|---|---|
| **Spellink の中継**(標準) | ほとんどの人。家の外でも使いたい | `config.json` に `"relayUrls": ["wss://jp.relay.spellink.uk", "wss://us.relay.spellink.uk"]` を足す。**運営が準備中です** |
| 家の直結 | 家の中だけで使う | `config.json` に `"lan": {"enabled": true}`。名前サービスの準備中です |
| 自分のトンネル | 上級者だけ | 自分のドメインと Cloudflare のトンネルを用意し、`"extraUrls": ["wss://あなたの住所/v1"]` を足す([手順](../../guides/cloudflare-tunnel-setup.md)) |

- **トンネルは任意です。** 中継を使うなら、要りません。設定が無くても、警告は出ません。
- 複数を同時に書けます。端末は、つながるものを使います。
- `config.json` を変えたら、ブリッジを再起動します([2. ブリッジを入れる](02-bridge.md#設定を変えたあとの再起動))。

## 登録
パソコンで、端末に付ける名前(自由。例: `my-nomad`)を決めて実行します。
```
spellink-bridge device add my-nomad
```
「手順 1/4 が終わりました」と出れば成功です。コマンドを実行したフォルダに、`Spellink-my-nomad.snplg`(設置ファイル)ができます。
- このファイルは、**その端末だけが使え、期限つき(既定 24 時間)**です。ペアリングが終わるまで、人に渡さないでください。
- 日本語で表示したいときは、`LANG=ja_JP.UTF-8 spellink-bridge device add my-nomad`。
- `already exists` と出たら、別の名前にするか、`spellink-bridge device list` で確かめます。

## 端末に入れる
1. `Spellink-my-nomad.snplg` を、端末の `MyStyle` フォルダに入れます(USB、または端末へのファイル送信)。
2. 端末で、「設定 → アプリ → プラグイン」から入れます。
3. **新しいノート**を作ります(古いノートには、ボタンが出ません)。

## ペアリング
| 手順 | どこで | 何をする |
|---|---|---|
| 3 | 端末 | Spellink の設定 →「ブリッジとペアリング」→「ペアリング」。**8 桁の数字と QR** が出る(既定で 90 秒だけ) |
| 4 | パソコン | 90 秒のうちに `spellink-bridge device pair` を実行し、8 桁を入れる |

- `spellink-bridge device pair 12345678` のように、数字を先に付けてもよいです。
- パソコンにカメラがあれば、`spellink-bridge device pair --web` でブラウザの読み取りページが開きます。**数字の入力が主で、QR は近道です。**
- 「その数字は受け付けられませんでした」: 端末の数字を確かめます。時間切れなら、端末でもう一度「ペアリング」を押します(5 回まちがえると、その窓は閉じます)。

端末に「ペアリングしました」と出て、`spellink-bridge device list` で `active` になれば完了です。
