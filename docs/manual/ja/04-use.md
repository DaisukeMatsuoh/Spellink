# 4. 使う

## 質問する
1. 新しいノートに、質問を手書きします。
2. ラッソで囲み、プラグインのボタン(**AI に聞く**)を押します。
3. 数秒〜数十秒で、答えが下に書かれます。続きを同じノートに書いて囲むと、会話が続きます。

覚えておくこと:
- 一度に 1 つの質問です。答えの途中で別のノートを開くと、書くのを止めます。
- 文字として読めないもの(楽譜・絵)を囲むと、「読み取れない」と出ます。
- AI に送るのは、読み取った文字と、同じノートの前の会話だけです。**画像は送りません。**
- 字間・傾きの設定と、会話の記憶は、パソコンに保存されます。「会話を忘れさせる」で消せます。

## Bridge App
パソコンで次を実行すると、ブラウザに Bridge App の画面(`/app`)が開きます。
```
spellink-bridge open
```
- **状態:** ブリッジの名前と版、Claude Code が見つかったか、中継が有効か。
- **端末:** 追加(`device add` と同じ)、一覧、ペアリングの状態。
- **AI の設定:** 次の節。

この画面は、**ブリッジと同じパソコンからだけ**開けます。端末や中継からは、設定を変えられません。

## AI の設定
Bridge App の「AI の設定」で、AI に渡す内容を決められます。すべて任意で、何も設定しなくても動きます。

| 項目 | 内容 |
|---|---|
| 日時と OS を伝える | 既定は**オン**。AI に、今の日時・タイムゾーン・OS の種類(`linux` など)を伝えます。「今は?」に答えるために要ります。ホスト名・ユーザー名・パス・IP は、伝えません |
| 常に伝える指示 | 呼び方・前提・口調など。例:「私は大輔です。予定は日本時間で答えて」。2000 文字まで |
| 許可するコマンド | AI にパソコンのコマンドを使わせたいときだけ。1 行に 1 つ、`Bash(date)` のように書きます。`Bash(*)` のような「すべて許可」は、保存できません。空なら、コマンドは使えません |

- 保存しても、動いているブリッジには、すぐ効きません。「ブリッジを再起動してください」と出たら、[再起動](02-bridge.md#設定を変えたあとの再起動)します。
- 許可するコマンドは、パソコンで本当に実行されます。**意味が分かるものだけ**書いてください。
- 画面を使わず、`config.json` の `ai` の節を、テキストエディタで書き換えてもできます(書式は [仕様](../../spec/ai-tools.md))。

> 日時を伝える機能は、実機での通し確認(「今は?」)を、これから行います。
