# 7. 送られるもの・残るもの

| 何が | どこへ | 備考 |
|---|---|---|
| 囲んだ手書きから読み取った**文字**と、同じノートの前の会話 | 端末 → ブリッジ → AI | 端末とブリッジのあいだは暗号化。**画像は送りません** |
| 日時・タイムゾーン・OS の種類 | ブリッジ → AI | 「AI の設定」でオフにできます。ホスト名・ユーザー名・パス・IP は送りません |
| AI のログイン情報 | どこにも渡りません | ブリッジは、あなたがログイン済みの Claude Code をそのまま呼ぶだけです |
| 設定・端末の登録・会話の記憶 | **あなたのパソコンだけ** | `~/.config/spellink-bridge/` など。本人だけが読める権限。**暗号化はしていません** |
| 端末 | 何も保存しません | ペアリングの鍵は、端末の保存領域にあります |

- **ペアリングのトークンは、ブリッジの鍵です。** 人に見せないでください。漏れたら、`device revoke` で端末を無効にし、やり直します。
- 中継を使うときも、中継には**暗号化された通信**と、どのブリッジの部屋かだけが見えます。質問と答えの中身は、見えません。
- 詳しくは [SECURITY.md](../../../SECURITY.md)。
