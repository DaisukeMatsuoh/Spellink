# Spellink マニュアル(利用者向け)

[English](../en/README.md) · 日本語(この版が元です)

Supernote で手書きを囲むと、あなたのパソコンの AI が答え、答えが**手書きの筆跡**でページに書き戻されます。
このマニュアルは、**初めての人が、インストールから使うところまで**を、順に進めるためのものです。

> **状態: 初期のアルファ版です。** Linux のパソコンと Supernote Nomad で動くことを確かめています。
> Windows と macOS は、実機でまだ確かめていません。中継(外出先から使う道)は、運営が準備中です。

## 全体像

```
 Supernote (プラグイン)  ──暗号化──▶  ブリッジ (あなたのパソコン)  ──▶  Claude Code (あなたの契約)
   手書きを囲む                          質問を AI に渡し、
   ◀── 答えが筆跡で書かれる ──            答えを筆跡に変えて返す
```

- **プラグイン**は端末に入れます。手書きを端末の中で文字にして、ブリッジに送ります。
- **ブリッジ**は、あなたのパソコンで動く小さなプログラムです。AI のログイン情報には触らず、あなたがログイン済みの Claude Code をそのまま呼び出します。
- 端末とブリッジのあいだは、2 つだけが持つ鍵で暗号化されます。
