# リリースまでの計画（2026-11-08）

「リリース」を、**第三者が、自分の Supernote と自分のパソコンで、手順書どおりに使える公開版**と仮定する（OSS として公開するかどうかは未決）。担当: **U**=ユーザー（実機・権限・判断）、**L**=この開発機のエージェント、**R**=遠隔・別のエージェントでもできる（コードと文書だけ）。状態: ✅ 済、🔶 一部、⬜ 未着手、⏸ 判断・実機待ち。

## 1. いまの位置
動いている（実機確認済み）のは、ラッソ → 認識 → AI → 筆跡の書き戻し、複数ページ、会話の記憶、wss＋Noise。**その後に入れた信頼性の改修（切断後の再開、再接続 3 回、フレーム・SDK 戻り値の検証、AI の無応答 10 秒、表で動く状態機械、など）は、実機で未確認。** 開発者本人の環境（ROCK 5B+、Cloudflare のトンネル）では動く。第三者が、自分で接続を用意する道は、まだない（M3）。
