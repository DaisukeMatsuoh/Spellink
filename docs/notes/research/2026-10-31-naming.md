# 名前の検討: Cloute か Clote か（2026-10-31）

狙い: note（ノート）と Claude を混ぜた名前にしたい。

## 英語ネイティブにはどう読まれるか（推定）
| 綴り | 読まれ方 | 連想 |
|---|---|---|
| **Cloute** | ほぼ確実に **clout**（/klaʊt/、「クラウト」）と読まれ、語末の e は黙字扱い | clout = 影響力・権力、または「殴打」。俗語の clout-chasing（注目稼ぎ）は否定的。note も Claude も連想しにくい |
| **Clote** | **/kloʊt/**（「クロウト」）。note・quote・wrote と韻を踏む | Claude（/klɔːd/〜/kloʊd/）の頭と note の語尾がそのまま重なる。wrote（書いた）にも近く、「書いて返す」製品に合う |

- 英語の母音規則（子音＋o＋子音＋e は「オウ」と読む: note, vote, wrote）に従うので、Clote は初見でも迷わず読める。
- clote は古語・方言で「ゴボウ（の実）」を意味するが、ほとんど知られていない。悪い意味はない。
  ゴボウの実は服にくっつく（マジックテープの着想元）ので、「ノートにくっつく答え」という小話にも使える。
- 同名のアプリ・ブランドは、軽く検索した範囲では見つからなかった（商標調査ではない）。

**結論: 音の混ぜ方としては Clote のほうが自然**。Cloute は「クラウト」と読まれてしまい、狙いが伝わらない。

## 注意点
- Anthropic の商標ガイドラインは、自社製品名に Claude（や Anthropic）を含めることを認めていない。
  Clote は Claude そのものではないが、「Claude + note から作った名前」と説明すると、Anthropic 公式の製品のように見える懸念が出る。
  宣伝文句では由来を強調せず、「Claude Code で動く」とだけ平文で書くのが安全。
- 将来 Claude 以外（Codex など）にも対応するなら、Claude 由来の名前は少し窮屈になる。
- 名前を変えるなら**公開前の今が一番安い**。プラグインの `pluginID` は名前と無関係なので変わらない。
  変わるのは `pluginKey`・`app.json`・リポジトリ名・表示名。
