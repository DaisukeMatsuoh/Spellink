# ブリッジ: AI への環境の情報と、許可した道具（ADR 0022）

状態: **確認済み（ユーザー、2026-11-27）・実装済み（2026-11-28。実機の確認は下の「実機」）。**

実装での調整（2026-11-28）: ①道具の記録は**ブリッジのログのみ**（履歴〔`history/`〕への記録は、今回は見送り。T5 の「履歴」は未実装）。②T3 は、端末が送る設定のメッセージ（`Settings`）に `ai` の項目がないことで、作りとして守られる（`config.json` を保存しても `ai` は残る: テスト `ai_survives_a_save`）。

対象: `bridge/src/provider/claudecode.rs`（起動の引数）、`bridge/src/provider.rs`（システムプロンプト）、`bridge/src/config.rs`（設定）。
状態を持つ処理は増やさない。道具の使用は、AI の内側の出来事で、run（`bridge-run.md`）には「活動あり」としてだけ伝わる。**run の表は変えない**（TextArrives・AiGoesSilent・AiFails の既存のマスで足りる。下の「run との関係」）。

## 設定（`config.json`）
```json
"ai": {
  "environment": true,
  "instructions": "私は大輔です。予定は日本時間で答えて。",
  "tools": { "allow": ["Bash(date)"] }
}
```
| キー | 型 | 既定 | 意味 |
|---|---|---|---|
| `ai.environment` | 真偽 | true | システムプロンプトに、日時とタイムゾーン、OS の種類を入れる |
| `ai.instructions` | 文字列 | なし | 利用者の常設の指示（呼び方・前提・口調など）。毎回のシステムプロンプトに、環境の情報の後ろへ足す。前後の空白は除く。2000 文字まで、改行とタブ以外の制御文字は不可（超えたら起動を拒否）。PC の `config.json` だけが元（T3）。テスト: `standing_instructions_are_…`、`the_owners_standing_instructions_are_added_after_the_environment` |
| `ai.tools.allow` | 文字列の配列 | なし（道具は無効） | Claude Code の許可規則（`Bash(<コマンドの型>)`）。1 つ以上あるときだけ道具を有効にする |

## 不変条件
- T1: 道具は、`ai.tools.allow` が**空でないときだけ**有効になる。ほかの場合は、これまでどおり `--tools ""`。
- T2: 許可リストにないコマンドは、実行されない。ブリッジは、リストを**作り変えない**（検証して、そのまま CLI に渡す）。
- T3: 設定を変えられるのは、PC のファイル（と、Bridge App の管理画面）だけ。端末・中継から届くメッセージのどれも、`ai` の設定を読み書きしない。
- T4: 環境の情報に入れるのは、日時（ISO 8601）、タイムゾーン名、OS の種類（`linux`・`macos`・`windows`）だけ。ホスト名・ユーザー名・パス・IP・設定の中身は入れない。
- T5: 道具の使用（コマンドと結果の先頭の一部）は、ブリッジのログと履歴に残る。秘密（鍵・トークン）は、規則の値にも、ログにも、出さない。
- T6: 取消と時間切れでは、AI の起動したコマンドも止まる（プロセスグループごと）。止めたあとに、コマンドが動き続けることはない。

## run との関係
- 道具の使用中に届く CLI の出力（`assistant` の `tool_use`、`user` の `tool_result`）は、`activity(true)`（モデルが動いている）として扱う。文字は出ないので、`TextArrives` にはならない。
- 無応答の時間切れ（`AiGoesSilent`）は、出力がない間隔で数える。道具の実行中も、出力（`tool_use` のあとの `tool_result`）があれば延びる。全体の上限は変えない。
- したがって、`bridge-run.md` の表（5 状態×17 イベント）は変わらない。

## 起動オプション
| 道具が無効（T1 の外） | 道具が有効 |
|---|---|
| `--tools ""` | `--tools Bash --allowedTools <規則…>` |
共通: `-p --output-format stream-json --verbose --include-partial-messages --strict-mcp-config --setting-sources "" --no-session-persistence --system-prompt <…>`。作業のフォルダは、空の一時フォルダ（これまでどおり。プロジェクトの `CLAUDE.md` やファイルを拾わない）。
