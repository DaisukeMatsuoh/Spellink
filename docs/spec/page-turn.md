# ページ追加と書き込みの手順（`plugin/src/sdk.ts` の `insertPageAfter` ほか）

対象: 回答が 1 ページに収まらないとき、直後に新しいページを挿入し、そのページへ書く手順。
一連の手順なので、縦軸は**手順**（これから行う手順）、横軸はその手順の**結果**。ノートアプリへの依頼はすべて 1 本ずつ（ADR 0014）。

## 手順
| 記号 | 手順 | 使う SDK |
|---|---|---|
| T1 | 開いているのが質問したノートか確認 | `getCurrentFilePath` |
| T2 | 保存（保存前の編集は、ページ挿入でキャッシュが読み直されて失われる） | `saveCurrentNote` |
| T3 | 挿入前のページ数を読む | `getNoteTotalPageNum` |
| T4 | 元のページのテンプレートを調べる | `getNotePageTemplate` |
| T5 | ページを挿入 | `insertNotePage` |
| T6 | 挿入後のページ数を読み、増えたか確かめる | `getNoteTotalPageNum` |
| T7 | そのページへ表示を移す | `jumpToPage` |
| T8 | ストロークを書く（T1 → 要素を作る → 点を入れる → 挿入 → 解放） | `getCurrentFilePath`、`createElement`、`setRange`/`add`、`insertPageElements` |

## 結果
| 記号 | 結果 |
|---|---|
| OK | 成功、期待どおりの値 |
| FAIL | `success: false`（呼び出しが通らない）または例外 |
| REF | `success: true` だが `result: false`（ホストが断った） |
| SIL | ホストが時間内に答えない |
| NOP | 開いているノートが違う |
| ODD | 値が期待と違う（数値でない、増えていない、名前がない など） |
| CAN | 利用者が取り消した（手順の途中で） |
| USR | 利用者が手順の途中でノートやページを動かした |

## 手順表
処理: **X0** = 何もせず中断（ノートは変わっていない）、**X1** = 中断（ノートが一部変わっている可能性あり。巻き戻さず、理由を伝える）、**X2** = 続行。次の手順は `→Tn`。

| 手順＼結果 | OK | FAIL | REF | SIL | NOP | ODD | CAN | USR |
|---|---|---|---|---|---|---|---|---|
| **T1 確認** | →T2 | X0 | — | X0 | X0 | X0 | X0 a | ノート移動は NOP、ページ移動は影響なし b |
| **T2 保存** | →T3 | X0 | X0 | X0 | ！ 他のノートを保存してしまう（T1 がない） | — | X0 a | 同上 |
| **T3 数** | →T4 | X0 | — | X0 | X0 | X0 | X0 a | 同上 |
| **T4 型** | →T5（名前があり md5 が空/0 ならそのテンプレート） | →T5（白紙で代用。記録する） | — | X0 | — | →T5（白紙） | X0 a | 同上 |
| **T5 挿入** | →T6 | X0 | X0 | X1 c | X0 | — | X0 a | 同上 |
| **T6 数** | 増えていれば →T7 | X1 d | — | X1 d | X1 d | X1（増えていない／数でない） | X1 | 同上 |
| **T7 移動** | →T8 | X1 | X2（記録して続行） e | X1 | X1 | — | X1 | 同上 |
| **T8 書込** | 完了 | X1 | X1 | X1 | X0（書かない） | X1（点の入力が偽） | X1（途中で止める） | ！ ページ番号のずれ f |

## 注
- a: 手順の途中での取消は、手順の境目では検査しない。各手順は短いので、完了してから止まる（回答の行の境目では検査する）。🟡
- b: 書き込みは、ページ番号を指定する。利用者が別のページを見ていても、書き込み先は変わらない（診断 8 で確認済み）。ノートそのものを別のものに替えると、T1 / T8 の確認で止まる。
- c: 時間切れでも、ホストの中で挿入が実行されているかもしれない。ノートに空のページが 1 枚増えている可能性がある。巻き戻さず、利用者に伝える。
- d: ページが増えたのかどうか分からない。回答は止める。
- e: 表示を動かすのは見た目だけの話で、書き込みには要らない。
- f: **穴**: 回答の最中に、利用者が（回答の対象より前に）ページを挿入・削除すると、`ctx.page + n` のページ番号がずれ、別のページに書く。T3 で読んだページ数と、挿入のたびのページ数を比べれば検出できる（⚠ 提案: 開始時のページ数を記録し、想定と違えば X1 で止める）❓。
- 実機の戻り値の確認: ブール値の `result` はトレースに記録される。`getNoteTotalPageNum` が数値以外を返す場合、T3/T6 は ODD になり、複数ページの回答が止まる。

## この表から出る修正（優先順）
1. T1 / T2: `insertPageAfter` の最初に `ensureOpen` を入れる（現状は保存が他のノートに作用しうる）。
2. T8 / USR: ページ数の変化の検出（仕様の確認が必要 ❓）。
3. 表の各マスに対応するテスト（`sdkSafety` に、T4 ODD、T7 FAIL、T8 の各行を追加）。
