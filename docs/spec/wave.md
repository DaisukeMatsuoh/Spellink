# 端末: 待機中の波線アニメーションと消し残しの掃除（`plugin/src/inkDrops.ts`）

対象: AI が考えている間、回答の位置に波線を少しずつ描き、最初の回答の行が来る直前に消す。設定でオフにできる（既定はオフ）。
回答そのものは波線に依存しない。波線の失敗で回答を止めてはいけないが、**消し残しは利用者のノートを汚す**。したがって、消し残しは**分かった時点でその場で消し、消せなければ記録して、次の質問の開始時に確認する**（決定 2026-11-07）。
波線の各ストロークには、1 回分で共通の一意な印（`Element.userData`、接頭辞 `spellink-wave:`）が付く。削除は「その印を持つ要素」だけ。

**この文書の表が、コードの表の元データ**（`npm run spec`。書式は ask-flow.md と同じ）。

## 状態
| 状態 | 意味 |
|---|---|
| OFF | 設定オフ、または開始前 |
| DRAWING | 周期的に 1 片ずつ描く |
| CLEARING | 印の付いた要素を読み、消している |
| LEFTOVER | 消せなかった。波線がページに残っている。ページと印を記録済み（終了状態） |
| STOPPED | 正常に終了。ページに波線は残っていない（終了状態） |

## イベント
| イベント | 意味 |
|---|---|
| START | アニメーションを始める（設定が on のとき） |
| TICK | 周期のタイマー |
| STOP | 最初の回答の行、取消、失敗、完了のどれかで止める |
| WRAP | 波線が右端に達した |
| AWAY | 利用者が別のページを見ている |
| FAIL | 描く・読む・消すの SDK 呼び出しが失敗・拒否・時間切れ。すでに描いた片がある |
| FAIL_CLEAN | 同じ失敗だが、描いた片がまだ 0（消すものがない） |
| MOVED | 開いているノートが違う（描いた片がある。消しに行けない） |
| CLEARED | 停止のための消去が成功した |
| WRAPPED | 周回のための消去が成功した |

## 処理（Action）
| 処理 | 内容 | 現状 | テスト |
|---|---|---|---|
| W1 | 何もしない（描いていないので消すものがない）。タイマーは止める | ✅ | `inkDrops` |
| W2 | 次の 1 片を、印つきで描く | ✅ | `inkDrops` |
| W3 | 停止: タイマーを止め、進行中の処理が終わるのを待ち、消す（消去を始める。成功は CLEARED） | ✅ | `inkDrops` |
| W4 | 周回: いったん全部消して、先頭から描き直す（消去を始める。成功は WRAPPED） | ✅ | `inkDrops` |
| W5 | 描かずに待つ（利用者が戻るまで） | ✅ | `inkDrops` |
| W6 | 描くのをやめる。**原因を記録する（`wave.giveUp`、描いた片数つき）**。描いた片をその場で 1 回だけ消す（成功は CLEARED、失敗は FAIL） | ✅ | `waveLeftovers` |
| W7 | **消し残しとして、ページ番号・ノートのパス・印を記録する（メモリ上）**。`wave.leftover` を記録 | ✅ | `waveLeftovers` |
| W8 | 消せた: 描いた片の数を 0 にする | ✅ | `inkDrops` |
| W9 | 開始: 周期のタイマーを動かす | ✅ | `inkDrops` |
| W10 | 周回の消去が済んだ: 描く位置を先頭に戻して続ける | ✅ | `inkDrops` |

## 注
- a: 終了後・開始前に、遅れて届いたもの（タイマーや進行中の処理の結果）。
- b: 消している間は、次の周期の処理を始めない（依頼は列で直列。前の処理が終わるまで次の周期は走らない）。
- c: すでに停止の処理に入っている、または終わっている。
- d: その状態では、そのイベントを生む処理が動いていない。

## 消し残しの掃除（次の質問の開始時）
質問の開始（ask-flow.md の PREP）で、対象ページを読み取る設定が on のとき、**同じ読み取りの結果を使って**確認する。ページを余計に読まない。

| 見つかったもの | 処理 |
|---|---|
| 印の接頭辞 `spellink-wave:` を持つ要素（どの質問が描いたものでも） | 削除する（`result` を確認）。成功したら記録を消す |
| 記録にあるが、このページにはない | すでに消えている（利用者が消した等）。記録を消す |
| 記録にあるページが、いま開いているページと違う | **何もしない**（ほかのページは読まない。全ページの走査は重いため）。記録は残す |
| 削除が失敗した | 記録は残し、`wave.sweepFailed` を記録。回答は止めない |

- 印の接頭辞で消してよい理由: 利用者の手書きに `spellink-wave:` が入ることはない。印は**確実な ID**であり、位置・本数・形の推測ではない。
- 記録はメモリ上だけ（端末に保存手段がない）。プラグインが再起動すると失われるが、**ページ自体に印が残っている**ので、次にそのページで質問したときの掃除が拾う。
