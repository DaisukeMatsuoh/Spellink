# 端末: 待機中の波線アニメーション（`plugin/src/inkDrops.ts`）

対象: Claude が考えている間、回答の位置に波線を少しずつ描き、最初の回答の行が来る直前に消す。設定でオフにできる（既定はオフ）。
回答そのものは波線に依存しない。波線の失敗で回答を止めてはいけないが、**消し残しは利用者のノートを汚す**ので、必ず記録する。
波線の各ストロークには、1 回分で共通の一意な印（`Element.userData`）が付く。削除は「その印を持つ要素」だけ。

## 状態
| 記号 | 状態 |
|---|---|
| W0 | OFF（設定オフ、または開始前） |
| W1 | DRAWING（周期的に 1 片ずつ描く） |
| W2 | CLEARING（印の付いた要素を読み、消している） |
| W3 | GAVEUP（異常が起きて、描くのをやめた。すでに描いた分が残っている可能性がある） |
| W4 | STOPPED（正常に終了。ページに波線は残っていない） |

## イベント
| 記号 | イベント |
|---|---|
| V1 | TICK（周期のタイマー） |
| V2 | STOP（最初の回答の行、取消、失敗、完了のどれかで止める） |
| V3 | WRAP（波線が右端に達した） |
| V4 | USER-AWAY（利用者が別のページを見ている） |
| V5 | SDK-FAIL（描く・読む・消すの SDK 呼び出しが失敗、拒否、時間切れ） |
| V6 | NOTE-MOVED（開いているノートが違う） |

## 処理
| 記号 | 処理 | 現状 | テスト |
|---|---|---|---|
| A1 | 何もしない（描いていないので消すものがない）。タイマーは止める | ✅ | `inkDrops` |
| A2 | 次の 1 片を、印つきで描く | ✅ | `inkDrops` |
| A3 | タイマーを止め、進行中の処理が終わるのを待ち、消す（A8） | ✅ | `inkDrops` |
| A4 | 周回: いったん全部消し、先頭から描き直す | ✅ | `inkDrops` |
| A5 | 描かずに待つ（利用者が戻るまで） | ✅ | `inkDrops` |
| A6 | 描くのをやめる。**原因を記録する（`wave.giveUp`、描いた片数つき）** | ✅（ADR 0014 で記録を追加） | ❌ 記録のテストなし |
| A7 | 消せなかった。記録する。波線がページに残る | ✅ 記録あり | ❌ |
| A8 | ページを保存して読み、印を持つ要素の番号を降順で削除（`result` を確認する） | ✅ | `inkDrops` |

## 注
- a: 波線を始めていない。
- b: タイマーは止まっている。
- c: 終了済み。
- 描く・読む・消すは、ノートアプリへの依頼として 1 本ずつ、他の依頼（走査、書き込み）と重ならない（ADR 0014）。
- **利用者に消し残しを知らせる方法**は決めていない ❓（案: 回答の完了時に、残っているときだけ短いダイアログ）。
